## 📖 About the Project
A system architecture project detailing the upgrade of legacy marine generator controllers to modern automation. This initiative significantly improves safety, reliability, and data logging capabilities for offshore power plants.

## ✨ Key Features
- 🔌 **Digital Overhaul**: Comprehensive redesign from analog control to digital management systems.\n- ⚖️ **Active Control Loops**: Precise voltage and frequency regulation algorithms.\n- 📊 **Real-time Diagnostics**: Enhanced integration for real-time monitoring and rapid fault diagnosis.
